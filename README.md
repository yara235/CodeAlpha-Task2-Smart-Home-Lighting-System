# Smart Home Lighting System

## Project Description

This project presents the design of a Smart Home Lighting System that automatically controls lighting based on motion detection. The system uses sensors and a controller to improve energy efficiency and user convenience.

## Objectives

* Design an automated lighting system.
* Reduce unnecessary energy consumption.
* Improve home automation efficiency.
* Understand the role of sensors in automation systems.

## System Components

* PIR Motion Sensor
* Microcontroller (Arduino)
* Relay Module
* LED Light
* Power Supply

## System Workflow

1. Detect movement using sensors.
2. Send signals to the controller.
3. Process sensor input.
4. Turn lights ON or OFF automatically.

## Advantages

* Energy saving
* Reduced electricity cost
* Convenience
* Improved automation

## Applications

* Smart Homes
* Offices
* Hospitals
* Educational Institutions
* Smart Buildings

## Conclusion

Smart lighting systems provide an efficient and cost-effective automation solution while reducing energy consumption and improving user experience.
